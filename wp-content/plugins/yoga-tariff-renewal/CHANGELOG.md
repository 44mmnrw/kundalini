# История версий — Yoga Tariff Renewal

## 1.1.1 — 2026-06-10

- Исправлено сохранение карты в ЮKassa для автопродления: при создании платежа через EPL/виджет `save_payment_method` теперь берётся из meta заказа (`_ytr_auto_renew_opt_in`), а не только из `$_POST` на чекауте.
- Фильтр `woocommerce_yookassa_create_payment_request` для сохранения карты выполняется с приоритетом 99 (после настроек темы).

## 1.1.0 — 2026-06-10

- Статус WP Cron в админке: последний запуск, просрочка, источник (cron / ручной), примеры crontab (PHP CLI и curl).
- Настройка частоты проверки продлений: 5 / 15 / 30 минут, час, 6 / 12 часов, сутки.
- Исправлено сравнение времени cron (UTC) для корректного статуса «просрочено».

## 1.0.0 — 2026-06-08

- Первый релиз: автопродление тарифов через ЮKassa, сохранённые карты в ЛК, cron-проверка, ручной запуск из админки.
