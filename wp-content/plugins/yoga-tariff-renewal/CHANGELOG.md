# История версий — Yoga Tariff Renewal

## 1.3.0 — 2026-06-19

- Добавлен стабильный ключ идемпотентности ЮKassa для каждого заказа автопродления.
- Добавлена блокировка одновременного запуска автопродления: общая блокировка процесса и отдельная блокировка пользователя.
- Исправлена обработка статусов `pending` и `waiting_for_capture`: ожидающие платежи больше не переводятся в `failed` и блокируют повторное списание до финального статуса.
- Добавлена синхронизация ожидающих платежей через ЮKassa перед новой попыткой списания.
- Добавлены настройки количества повторных попыток и интервала между ними.
- Добавлено письмо пользователю при финальной ошибке автосписания.
- Добавлена проверка настроек чеков ЮKassa в админке плагина.
- Усилено сохранение карты при оплате тарифа: для тарифного заказа сохраняются признаки автопродления и тип оплаты, чтобы ЮKassa получила `save_payment_method`.

## 1.2.1 — 2026-06-10

- Режим заглушки (`ytr_stub_recurring`): привязка карты и автопродление без `save_payment_method` в ЮKassa.
- Сообщение на русском при ошибке forbidden / recurring payments.

## 1.2.0 — 2026-06-10

- Привязка карты в ЛК: «Добавить карту» → платёж ЮKassa с `save_payment_method` → возврат в кабинет.
- После привязки карта в списке; при активном тарифе включается автопродление.
- Настройка суммы привязки (по умолчанию 1 ₽).

## 1.1.1 — 2026-06-10

- Исправлено сохранение карты в ЮKassa для автопродления: при создании платежа через EPL/виджет `save_payment_method` теперь берётся из meta заказа (`_ytr_auto_renew_opt_in`), а не только из `$_POST` на чекауте.
- Фильтр `woocommerce_yookassa_create_payment_request` для сохранения карты выполняется с приоритетом 99 (после настроек темы).

## 1.1.0 — 2026-06-10

- Статус WP Cron в админке: последний запуск, просрочка, источник (cron / ручной), примеры crontab (PHP CLI и curl).
- Настройка частоты проверки продлений: 5 / 15 / 30 минут, час, 6 / 12 часов, сутки.
- Исправлено сравнение времени cron (UTC) для корректного статуса «просрочено».

## 1.0.0 — 2026-06-08

- Первый релиз: автопродление тарифов через ЮKassa, сохранённые карты в ЛК, cron-проверка, ручной запуск из админки.
